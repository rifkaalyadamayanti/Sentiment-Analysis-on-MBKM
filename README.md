# Sentiment-Analysis-on-MBKM

## Deskripsi

Proyek ini bertujuan menganalisis sentimen masyarakat terhadap kebijakan **Merdeka Belajar Kampus Merdeka (MBKM)** menggunakan data hasil scraping dari platform X (Twitter). Tahapan yang dilakukan meliputi preprocessing teks, eksplorasi data, visualisasi, ekstraksi fitur, serta pembangunan model machine learning untuk mengklasifikasikan sentimen menjadi positif, negatif, dan netral.
